# Calculator

A focused, keyboard-friendly calculator with a dark glass interface.

## Live site

After GitHub Pages is enabled, the application is published at:

https://aragoncodes.github.io/vibed-calculator/

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run typecheck
npm run build
```

## Deployment

Pushes to `main` are verified, built, and deployed to GitHub Pages automatically by the workflow in `.github/workflows/deploy-pages.yml`.
